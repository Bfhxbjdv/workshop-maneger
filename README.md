## 👥 أدوار المستخدمين

### 1. 👑 المدير (Admin)

#### ✅ الصلاحيات
- كل صلاحيات المصمم والمشغلين
- إدارة المستخدمين (إضافة/تعديل/حذف)
- إنشاء وإدارة الفواتير
- إدارة المصروفات (إضافة/تعديل/حذف)
- لوحة التحكم مع إحصائيات شاملة
- النسخ الاحتياطي لقاعدة البيانات
- مزامنة الملفات مع Google Drive
- عرض سجل النشاطات ومعلومات النظام

#### 🧭 طريقة الاستخدام

**الصفحة الرئيسية (`/`)** — لوحة تحكم:
```
┌─────────────────────────────────────────┐
│ إجمالي الطلبات | قيد التنفيذ | العملاء   │
│ آخر الطلبات (5) | إحصائيات الحالة       │
│ مخزون منخفض | روابط سريعة              │
└─────────────────────────────────────────┘
```

**إدارة العملاء (`/clients`)**:
1. البحث عن عميل بالاسم
2. إضافة عميل جديد بالضغط على "إضافة عميل"
3. النقر على "عرض" لرؤية جميع طلبات العميل وملفاته
4. تعديل أو حذف عميل من أزرار التحكم

**إنشاء طلب جديد (في صفحة المصمم أو من `/`)**:
1. اختيار العميل من قائمة البحث
2. اختيار نوع الماكينة (ليزر/راوتر)
3. إضافة الخامات المستخدمة مع الكميات
4. كتابة ملاحظات (اختياري)
5. الضغط على "إنشاء الطلب"

**إنشاء فاتورة**:
1. من صفحة الطلبات: الضغط على أيقونة الفاتورة `📄` بجانب الطلب المُسلَّم
2. إدخال المبلغ الإجمالي
3. يتم إنشاء PDF تلقائياً مع خصم المخزون وحساب الربح

**لوحة التحكم (`/admin`)** — تبويبات:
- **الإحصائيات**: عرض إجمالي المستخدمين، العملاء، الطلبات، الفواتير، الإيرادات، المصروفات
- **المصروفات**: إضافة وتعديل وحذف المصروفات اليومية
- **مزامنة Drive**: عرض قائمة انتظار رفع الملفات إلى Google Drive، إعادة محاولة العناصر الفاشلة، مزامنة يدوية
- **النسخ الاحتياطي**: إنشاء نسخة احتياطية من قاعدة البيانات وعرض النسخ السابقة
- **سجل النشاطات**: عرض جميع الإجراءات المسجلة في النظام
- **معلومات النظام**: إصدار Node.js، زمن التشغيل، استخدام الذاكرة، حجم قاعدة البيانات، حالة Drive

### 2. ✏️ المصمم (Designer)

#### ✅ الصلاحيات
- إنشاء وتعديل وحذف الطلبات
- إدارة العملاء (إضافة/تعديل)
- رفع ملفات التصميم (DXF, CDR, AI, EPS, SVG, PDF, PLT ...)
- تحميل الملفات المرفوعة
- تكرار الطلبات
- إدارة المخزون (إضافة/تعديل مواد)
- عرض الفواتير (لا يمكن إنشاؤها)

#### 🧭 طريقة الاستخدام

**صفحة المصمم (`/`)** :
```
┌─────────────────────┬────────────────────────────┐
│  طلب جديد            │  قائمة الطلبات (تبويبات)   │
│ ┌───────────────┐   │  كل الطلبات | قيد التصميم   │
│ │ العميل         │   │  جاهز للقص | الخ           │
│ │ نوع الماكينة   │   │                            │
│ │ الخامات        │   │  # | العميل | النوع | حالة  │
│ │ ملاحظات        │   │  خامات | تحميل | خيارات    │
│ └───────────────┘   │                            │
└─────────────────────┴────────────────────────────┘
```

**إنشاء طلب جديد**:
1. اكتب اسم العميل في حقل البحث واختره
2. اختر نوع الماكينة (ليزر/راوتر)
3. أضف الخامات المستخدمة بتحديد المادة والكمية
4. أضف ملاحظات (اختياري)
5. اضغط "إنشاء الطلب"

**رفع ملف تصميم**:
1. في جدول الطلبات، الضغط على أيقونة الرفع `⬆️` بجانب الطلب "قيد التصميم"
2. اختيار ملف التصميم من الجهاز
3. تحديد الخامات المستخدمة مع الكميات
4. الضغط على "رفع الملف"
5. بعد الرفع: حالة الطلب تتغير إلى "جاهز للقص" تلقائياً

> 📁 الملفات تُرفع محلياً وإلى Google Drive تلقائياً (إذا توفر الإنترنت).

**تحديث حالة الطلب**:
1. الضغط على أيقونة القلم `✏️` بجانب الطلب
2. اختيار الحالة الجديدة من القائمة
3. حفظ التغيير

**إدارة المخزون (`/inventory`)**:
1. إضافة مادة جديدة (الاسم، السماكة، الكمية، سعر الوحدة)
2. تعديل مواد موجودة
3. المواد ذات كمية أقل من 5 تظهر بخلفية حمراء

## 📋 حالات الطلب (سير العمل)

```
قيد التصميم ──(رفع ملف)──► جاهز للقص ──(بدء التنفيذ)──► قيد التنفيذ
                                                              │
                                                              ▼
                                                         تم التغليف
                                                              │
                                                              ▼
                    فاتورة ◄──(إنشاء فاتورة)── تم التسليم ◄───┘
```

- **قيد التصميم**: تم إنشاء الطلب، لم يُرفع ملف بعد
- **جاهز للقص**: تم رفع ملف التصميم، المشغل جاهز للبدء
- **قيد التنفيذ**: الماكينة تعمل على تنفيذ الطلب
- **تم التغليف**: تم قصه وتغليفه، ينتظر الاستلام
- **تم التسليم**: تم تسليمه للعميل (يخصم المخزون ويحسب التكلفة والربح)

## 🛠️ الصيانة

### إعادة تشغيل السيرفر
- النظام يعمل تلقائياً عند فتح اللابتوب (مهمة مجدولة)
- إذا توقف السيرفر، الـ Watchdog يعيد تشغيله تلقائياً خلال ثوانٍ

### النسخ الاحتياطي
1. اذهب إلى `/admin` ← تبويب "النسخ الاحتياطي"
2. اضغط "إنشاء نسخة احتياطية"
3. النسخ تُحفظ في مجلد `backups/`

### استكشاف الأخطاء

| المشكلة | الحل |
|---------|------|
| لا يمكن الدخول للصفحة | تأكد أن السيرفر شغال (راجع `run.bat`) |
| الملفات لا ترفع إلى Drive | من `/admin` ← مزامنة Drive ← "إعادة محاولة" و"مزامنة الآن" |
| المخزون لا يخصم تلقائياً | تأكد من ربط الخامات مع الطلب في نافذة رفع الملف |
| إشعارات لا تظهر | الصفحة تُحدث تلقائياً عبر Socket.IO — نفش الصفحة يدوياً |
| النافذة المنبثقة لا تظهر | الصفحة تُحدث تلقائياً عبر Socket.IO — نفش الصفحة يدوياً |
